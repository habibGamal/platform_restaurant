   - resolve(PeriodPreset $preset, CarbonImmutable $today, ?CarbonImmutable $from = null, ?CarbonImmutable $to = null, ?string $nowTime = null): Period
       today → [today,today]; yesterday; this_week → [Saturday of this week, today]; last_week → previous Sat..Fri; this_month → [1st, today]; last_month; this_quarter → [quarter start, today]; this_year → [Jan 1, today]; last_30_days → [today-29, today]; last_8_weeks → [Saturday 7 weeks before this week's Saturday, today]; custom → [from,to] (both required, else InvalidArgumentException).
       When the resolved period ends on $today, cutoffTime = $nowTime (may be null); otherwise null.
   - defaultComparison(PeriodPreset $preset): ComparisonMode — today, yesterday, this_week, last_week → same_weekday_last_week; this_quarter, this_year → same_period_last_year; everything else → previous.
   - comparison(Period $current, ComparisonMode $mode, ?PeriodPreset $preset = null): ?Period
       none → null.
       same_weekday_last_week → current shifted by −7 days.
       same_period_last_year → current shifted by −364 days (weekday aligned).
       previous →
         * if preset ∈ {this_week, this_month, this_quarter, this_year} (calendar-to-date): start of the PREVIOUS unit + the same number of elapsed days, clipped to that unit's last day (e.g. this_month on Oct 14 → Sep 1..Sep 14; on Mar 31 this_month → Feb 1..Feb 28/29).
         * if preset ∈ {last_week, last_month}: the full previous unit before it (last_month = Sep → Aug 1..Aug 31).
         * otherwise: the immediately preceding range of equal length (to = current.from − 1 day).
       The comparison keeps current->cutoffTime.

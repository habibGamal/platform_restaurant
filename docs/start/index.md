# البداية السريعة

تتيح **منصة المطاعم** لمالكي السلاسل والمحللين ومديري الفروع متابعة مبيعات الفروع وأرباحها وتكاليفها وأهدافها من لوحة مركزية واحدة متصلة بنقاط البيع.

## ما الذي تقدمه المنصة؟

- **لوحة تقارير متعددة الفروع:** مقارنة أداء الفروع والعلامات التجارية داخل المنظمة الواحدة عبر لوحة `/app` مع عزل البيانات حسب الصلاحيات.
- **مؤشرات مالية وتشغيلية موحدة:** متابعة المبيعات، مجمل الربح، صافي الربح، نسبة تكلفة الخامات، الهالك، عجز الجرد، وعجز النقدية وفق معادلات قياسية واحدة.
- **إدارة الأهداف والترتيب:** تحديد أهداف شهرية للفروع مع توزيع يومي يراعي أوزان أيام الأسبوع ويستبعد أيام المواسم، وترتيب الفروع عبر 7 مؤشرات.
- **مراقبة حالة البيانات والاتصال:** التحقق من نبضات الاتصال الدورية بنقاط البيع ومطابقة مجاميع المنصة مع ملخص اليوم المرسل من نقطة البيع.
- **المساعد الذكي وإدارة القائمة:** طرح أسئلة تحليلية بالعربية في صفحة المساعد الذكي (`/assistant`) ومراجعة أدوار الأصناف وبطاقاتها والكومبوهات المقترحة.

## من أين تبدأ؟

<div class="steps">

1. تعرّف على اللوحات وصلاحيات كل دور في صفحة [تسجيل الدخول واللوحات](/start/first-login).
2. أضف المطاعم والفروع وأنشئ رمز الربط من [إدارة الفروع ورموز الربط](/admin/branches) و[ربط نقطة البيع بالمنصة](/integrations/pos).
3. اضبط [تحديد الأهداف وأحداث التقويم](/admin/targets) و[معايير التقييم وتصنيفات المصروفات](/admin/scoring-and-expenses).
4. ابدأ قراءة الأرقام اليومية من [الفلاتر والفترات والمقارنة](/guide/filters-and-periods) و[لوحة التحكم الرئيسية](/guide/overview).

</div>

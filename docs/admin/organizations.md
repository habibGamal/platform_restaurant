# المنظمات والمطاعم ومجموعات الفروع

تتيح هذه الشاشات لمشغّل المنصة ومالكي المنظمات تنظيم الهيكل الإداري الذي يجمع العلامات التجارية والفروع ومجموعات المقارنة.

## 1. المنظمات (في لوحة المشغّل `/admin`)

تُنشأ **المنظمات** وتُدار حصرياً من لوحة المشغّل عبر <span class="path">لوحة المشغّل › المنظمات</span>:

| الحقل | الوظيفة |
|---|---|
| **اسم المنظمة** | الاسم المعروض للمجموعة أو السلسلة. |
| **المعرف الفريد (Slug)** | معرّف نصي فريد للمنظمة. |
| **الخطة** | باقة الاشتراك: **أساسي** أو **احترافي** (تشترط ميزة المساعد الذكي باقة **احترافي**). |
| **تفعيل الذكاء الاصطناعي** | مفتاح التشغيل العام لخدمات المساعد الذكي للمنظمة. |
| **المنطقة الزمنية** | المنطقة الزمنية الافتراضية (`Africa/Cairo`). |
| **العملة** | العملة الافتراضية للتقارير (`EGP`). |

## 2. المطاعم

تمثل **المطاعم** العلامات التجارية أو المفاهيم المختلفة داخل المنظمة الواحدة.

<div class="steps">

1. افتح <span class="path">الإدارة › المطاعم</span> في `/app` (أو <span class="path">المطاعم</span> في `/admin`).
2. اضغط زر الإضافة، ثم أدخل **اسم المطعم** (مع اختيار **المنظمة** إذا كنت في `/admin`).
3. احفظ السجل ليظهر المطعم في قائمة النطاق العلوية وعند إنشاء الفروع.

</div>

يعرض جدول **المطاعم** في `/app` الأعمدة التالية: **اسم المطعم**، **عدد الفروع**، و**تاريخ الإنشاء**.

## 3. مجموعات الفروع

تتيح **مجموعات الفروع** حفظ مجموعات مخصصة من الفروع (مثل فروع القاهرة أو الفروع الجديدة) لاستخدامها بسرعة في فلتر **مجموعة الفروع** داخل التقارير.

<div class="steps">

1. افتح <span class="path">الإدارة › مجموعات الفروع</span> في `/app`.
2. اضغط زر الإضافة وأدخل **اسم المجموعة**.
3. اختر **الفروع** المطلوبة من الفروع المصرح لك بالوصول إليها.
4. إذا كنت تملك صلاحية إدارة المستخدمين، يمكنك تفعيل خيار **على مستوى المنظمة** لإتاحة المجموعة لجميع مستخدمي المنظمة؛ وعند تركه مغلقاً تصبح المجموعة **خاصة** بك وحدك.

</div>

::: tip نصيحة
يستطيع **مدير فرع** لديه صلاحية عرض أكثر من فرع إنشاء مجموعات **خاصة** به، بينما يقتصر إنشاء وتعديل المجموعات التي نوعها **على مستوى المنظمة** على **مالك** المنظمة.
:::

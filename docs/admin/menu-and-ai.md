# إدارة القائمة وإعدادات المساعد الذكي

تتيح هذه الشاشات لمالك المنظمة إعداد مزود خدمة **المساعد الذكي** وضبط ميزانيته الشهرية، ومراجعة مخرجات تحليل القائمة الليلي وتثبيتها.

::: warning تنبيه
تظهر هذه الشاشات لمن يملك صلاحية إدارة الذكاء الاصطناعي (`ai.manage`) عندما تكون المنظمة على باقة **احترافي** ومفعّل لها خيار **تفعيل الذكاء الاصطناعي**.
:::

## 1. إعدادات المساعد الذكي

افتح <span class="path">الإدارة › إعدادات المساعد الذكي</span> واضبط الأقسام التالية:

| القسم | الحقول والإعدادات |
|---|---|
| **مزود خدمة الذكاء الاصطناعي** | **مزود الخدمة (Provider)**، **اسم النموذج (Model)** مع شارة **معتمد وموثق** أو **غير معتمد بعد**، **مستوى التفكير (Reasoning Level)** (`سريع`، `متوازن`، `عميق`)، و**مزودو الخدمة الاحتياطيون (Failover)** بحد أقصى 3 مزودين. |
| **مفتاح الربط الخاص بك (BYO API Key)** | إدخال **مفتاح الربط (API Key)** لتخزينه مشفراً، أو الضغط على **«إزالة المفتاح الخاص»** لحذفه. |
| **الميزانية والتحكم بالتكاليف** | عرض **ملخص الاستهلاك الشهري** بالجنيه المصري، وتحديد **الميزانية الشهرية للمؤسسة**، و**الحد الأقصى الشهري لكل مستخدم**، و**نسبة التحذير (%)**، وخيار **إيقاف تلقائي صارم عند استنفاد الميزانية**. |
| **إقرار مشاركة البيانات** | تفعيل الموافقة على إرسال الأرقام والإحصائيات المجمعة إلى مزود الخدمة المختار (لا تُرسل بيانات شخصية للعملاء). |

<div class="steps">

1. أكمل الإعدادات والميزانية وعلّم خانة الموافقة في **إقرار مشاركة البيانات**.
2. اضغط **«حفظ التعديلات»** في أعلى الصفحة.
3. اضغط **«اختبار الاتصال»** للتحقق من نجاح الربط بالمزود المختار.
4. يمكنك الانتقال مباشرة عبر زر **«فتح المساعد»** أو **«مراجعة أدوار الأصناف»**.

</div>

## 2. مراجعة أدوار الأصناف

افتح <span class="path">الإدارة › أدوار الأصناف</span> لمراجعة دور كل صنف في القائمة. تظهر الأصناف غير المصنفة أو منخفضة الثقة أولاً.

- اختر من عمود **الدور** تصنيف الصنف: **طبق رئيسي**، **طبق جانبي**، **مشروب**، **حلو**، **إضافة**، **كومبو/عرض**، **سطر تسوية**، أو **خامة**.
- أي دور تختاره يحصل على علامة **حددته أنت** في عمود **المصدر** ولا يغيّره التصنيف التلقائي.
- اضغط **«إعادة التصنيف»** في أعلى الصفحة لجدولة تصنيف الأصناف التي ليس لها دور موثوق.

## 3. بطاقات الأصناف

افتح <span class="path">الإدارة › بطاقات الأصناف</span> لمراجعة بطاقة كل صنف وتعديل:

- **عدد الأفراد**: عدد الأشخاص الذين يكفيهم الصنف.
- **الفئة**: **فردي**، أو **مشاركة**، أو **عائلي**.
- **الموسم**: **طول السنة**، أو **شتوي**، أو **صيفي**، أو **رمضان**، أو **صيامي**.
- **أعمدة العرض**: **المكونات** المستخرجة من الوصفة، و**سعر البيع**، و**التكلفة**، و**له وصفة**.
- اضغط **«إعادة بناء البيانات»** لجدولة إعادة بناء بطاقات الأصناف والكومبوهات مع الحفاظ على القيم التي حددتها بنفسك.

## 4. تصنيف الخامات

افتح <span class="path">الإدارة › تصنيف الخامات</span> لمراجعة تصنيف مكونات الوصفات في عمود **النوع** (مثل: **لحمة**، **فراخ**، **سي فود**، **رز**، **عيش**، **سلطة**، **صوص**، **شوربة**، **خضار**، **مشروب**، **حلو**، **تغليف**، **أدوات أكل**، **حاجة تانية**). يمكن تصفية الجدول بخيار **غير الموثوقة فقط**، ويُحفظ أي تعديل تختاره نهائياً ليظهر أثره في بطاقات الأصناف بعد البناء الليلي التالي.

## 5. الكومبوهات المقترحة

افتح <span class="path">الإدارة › الكومبوهات المقترحة</span> لمراجعة الوجبات المجمعة التي يقترحها التحليل الليلي:

- صفِّ الجدول حسب **الفترة** (بما فيها **آخر 90 يوم** أو الشهور)، و**القالب** (**وجبة فردية**، **عزومة عائلية**، **بوكس مشاركة**)، و**القناة**، و**الحالة** (**مقترح**، **معتمد**، **مرفوض**).
- راجع **الصنف الأساسي**، و**التشكيلة**، و**السعر الأصلي**، و**السعر المقترح**، و**هامش الربح**، و**الخصم**، و**الدليل**، وعمود **تنبيه** عند التشابه مع كومبو موجود.
- استخدم أزرار الإجراءات في نهاية كل صف: **«اعتماد»** أو **«رفض»** (مع إمكانية كتابة **ملاحظة (اختياري)**)، أو **«رجوع لمقترح»**.

# المستخدمون والصلاحيات

تتيح هذه الشاشة لمشغّل المنصة ولمالك المنظمة إنشاء حسابات المستخدمين وتحديد أدوارهم والفروع المسموح لهم بالوصول إليها.

## إضافة مستخدم من لوحة المنظمة (`/app`)

افتح <span class="path">الإدارة › المستخدمون</span> في `/app` ثم نفّذ الخطوات التالية:

<div class="steps">

1. اضغط زر الإضافة في أعلى القائمة.
2. أدخل **الاسم**، و**البريد الإلكتروني**، و**كلمة المرور** (مطلوبة عند الإنشاء).
3. اختر **الدور** من القائمة: **مالك**، أو **محلل**، أو **مدير فرع**.
4. عند اختيار **مدير فرع** يظهر حقل **الفروع المصرح بها**؛ حدد الفروع التي يُسمح له بمشاهدتها.
5. احفظ الحساب ليتمكن المستخدم من تسجيل الدخول إلى `/app`.

</div>

::: warning تنبيه
يمنع النظام المالك الوحيد للمنظمة من حذف حسابه أو التنازل عن دور **مالك** قبل تعيين مالك آخر للمنظمة.
:::

## إضافة مستخدمي المنظمات من لوحة المشغّل (`/admin`)

يستطيع مشغّل المنصة (`operator`) إنشاء وتعديل مستخدمي المنظمات عبر <span class="path">لوحة المشغّل › المستخدمون</span> باختيار **المنظمة** و**الدور** (`مالك`، `محلل`، `مدير فرع`) وتحديد **الفروع المصرح بها** لمدير الفرع. لا يمكن نقل مستخدم حالي إلى منظمة أخرى بعد إنشائه، كما يمنع النظام حذف أو تغيير دور المالك الوحيد للمنظمة.

::: tip نصيحة
ترتبط صلاحيات تعديل إعدادات المنظمة (المستخدمين، الأهداف، معايير التقييم، وتصنيفات المصروفات، وإعدادات المساعد) بأدوار محددة ثابتة في النظام، بينما يقتصر دور **محلل** على القراءة والتحليل، ودور **مدير فرع** على فروع محددة.
:::

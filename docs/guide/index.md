# دليل المستخدم

يجري إعداد دليل الاستخدام العربي الكامل في إصدار لاحق بالاعتماد على توصيفات التقارير المعتمدة. ستغطي صفحات الدليل المحاور التالية:

## 1. لوحة التحكم الرئيسية ومتابعة الفروع

- قراءة بطاقات المؤشرات الرئيسية: المبيعات، صافي الربح، هامش الربح، عدد الطلبات، متوسط قيمة الطلب، المصروفات، المشتريات، والهالك.
- استخدام شريط النطاق العلوي لاختيار المطعم، مجموعة الفروع، أو فروع محددة، وتفعيل مقارنة نفس الفروع (Like-for-Like).
- فهم شارات اكتمال البيانات (`مكتمل`، `مغلق غير مسوى`، `مباشر`، `مفقود`).

## 2. التقارير التحليلية

يغطي الدليل التقارير العشرة المتاحة حالياً في لوحة `/app`، إضافة إلى التحليلات التكميلية المخطط إضافتها لاحقاً:

- **لوحة التحكم الرئيسية** (`/app/reports/overview`)
- **مقارنة المبيعات** (`/app/reports/sales`) — تفكيك تغير المبيعات (أثر الطلبات وأثر الفاتورة) وتوزيع القنوات وطرق الدفع
- **الأرباح والهوامش** (`/app/reports/profitability`) — قائمة الأرباح والخسائر، وتحميل العمالة والإيجار
- **تكلفة الخامات والهالك** (`/app/reports/food-cost`) — أعلى الأصناف هالكاً، فروق الجرد، وتغير أسعار المشتريات
- **أداء الأصناف** (`/app/reports/products`) — تحليل باريتو 80/20 والأصناف الأكثر والأقل مبيعاً والأصناف غير المباعة
- **الورديات وأيام الأسبوع** (`/app/reports/shifts`) — خريطة الساعات الحرارية، أداء الكاشيرات، وعجز النقدية
- **ترتيب الفروع** (`/app/reports/ranking`) — التقييم الموزون عبر 7 مؤشرات واستبعاد الفروع ناقصة البيانات
- **المستهدف مقابل المحقق** (`/app/reports/targets`) — التوزيع اليومي، الإنجاز المتراكم، والتوقع لنهاية الشهر
- **المصروفات والمشتريات** (`/app/reports/expenses`) — الميزانية مقابل الفعلي، الموردون، والمشتريات مقابل تكلفة المبيعات
- **حالة البيانات والاتصال** (`/app/reports/data-health`) — نبضات الفروع، تقويم الاكتمال، تسوية الفروق، والمستندات المرفوضة

## 3. الأهداف ومعايير التقييم وإدارة القائمة

- تحديد أهداف الفروع والمطاعم (`تحديد الأهداف`)، نسخ الشهر السابق، وإضافة أحداث التقويم (رمضان والأعياد).
- ضبط أوزان معايير التقييم السبعة وتعيين تصنيفات المصروفات (`عمالة`، `إيجار`، وغيرها).
- مراجعة أدوار الأصناف، بطاقات الأصناف، تصنيف الخامات، واعتماد الكومبوهات المقترحة.

## 4. المحلل الذكي

- طرح الأسئلة التحليلية بالعربية في صفحة المساعد الذكي (`/assistant`) ومتابعة سجل العمل المباشر.
- فهم حدود الصلاحيات، التحفظات الخاصة باكتمال البيانات، وحفظ قرارات الكومبوهات.

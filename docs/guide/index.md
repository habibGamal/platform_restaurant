# دليل الاستخدام

يشرح هذا القسم لمالك المنظمة ومحللها ومدير الفرع كيف يقرأ تقارير المنصة كل يوم وكيف يستخدم المساعد الذكي.

## ابدأ من هنا

- [الفلاتر والفترات والمقارنة](./filters-and-periods): كيف تختار المطعم والفروع والفترة وطريقة المقارنة. تنطبق هذه الفلاتر على كل التقارير.

## التقارير

تجد التقارير في القائمة الجانبية تحت مجموعة **التقارير** في لوحة المنظمة (`/app`). يحتاج فتحها إلى صلاحية عرض التحليلات.

| التقرير | السؤال الذي يجيب عنه |
|---|---|
| [لوحة التحكم الرئيسية](./overview) | كيف كان أداء المجموعة اليوم أو في الفترة المختارة؟ |
| [مقارنة المبيعات](./sales-comparison) | لماذا زادت المبيعات أو نقصت، وفي أي فرع؟ |
| [الأرباح والهوامش](./profitability) | كم ربح كل فرع، وأين يضيع الهامش؟ |
| [تكلفة الخامات والهالك](./food-cost-and-waste) | هل تكلفة الخامات والهالك وعجز الجرد ضمن الحدود؟ |
| [أداء الأصناف](./product-performance) | ما الأصناف التي تبيع وتربح، وما الأصناف الراكدة؟ |
| [الورديات وأيام الأسبوع](./shifts-and-weekdays) | متى يزدحم العمل، وكيف أداء الورديات والكاشير؟ |
| [ترتيب الفروع](./branch-ranking) | أي الفروع الأفضل أداءً عند جمع عدة مؤشرات؟ |
| [المستهدف مقابل المحقق](./targets-vs-actual) | هل يسير كل فرع نحو مستهدف الشهر؟ |
| [المصروفات والمشتريات](./expenses-and-purchases) | أين تذهب المصروفات والمشتريات، وهل تتجاوز الميزانية؟ |
| [حالة البيانات والاتصال](./data-health) | هل وصلت بيانات كل الفروع كاملة وصحيحة؟ |

## المساعد الذكي

- [المساعد الذكي](./ai-analyst): اطرح أسئلتك بالعربية واحصل على إجابة مبنية على أرقام التقارير.

::: tip نصيحة
قبل أن تعتمد على رقم في أي تقرير، راجع صفحة [حالة البيانات والاتصال](./data-health). الفرع الذي لم يرسل بياناته كاملة يظهر بأرقام أقل من الحقيقة.
:::

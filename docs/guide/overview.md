# لوحة التحكم الرئيسية

تعرض لك هذه اللوحة صورة سريعة عن أداء المجموعة أو الفروع المختارة في الفترة المحددة. هي الصفحة التي يبدأ بها المالك والمدير يومه.

افتح <span class="path">التقارير › لوحة التحكم الرئيسية</span> (`/app/reports/overview`). الفترة الافتراضية هي **اليوم**. لتغييرها راجع [الفلاتر والفترات والمقارنة](./filters-and-periods).

## بطاقات المؤشرات

يظهر في أعلى الصفحة صف من البطاقات، وكل بطاقة تعرض قيمة الفترة ونسبة التغير عن فترة المقارنة:

| البطاقة | المعنى |
|---|---|
| **المبيعات** | قيمة المبيعات في الفترة. |
| **صافي الربح** | ما يبقى بعد خصم تكلفة المبيعات والمصروفات والهالك وعجز الجرد. |
| **هامش الربح** | صافي الربح كنسبة من المبيعات. |
| **عدد الطلبات** | عدد الطلبات المكتملة. |
| **متوسط قيمة الطلب** | المبيعات مقسومة على عدد الطلبات. |
| **المصروفات** | المصروفات المسجلة في الفروع. |
| **المشتريات** | فواتير الشراء في الفترة. |
| **الهالك** و**نسبة الهالك** | قيمة الهالك ونسبته من المبيعات. |

## الأقسام التالية

- **اتجاه المبيعات**: رسم للمبيعات عبر الفترة، كإجمالي أو **حسب الفرع**.
- **أداء الفروع**: جدول لكل فرع يضم المبيعات والطلبات ومتوسط الطلب ومجمل الربح وصافي الربح وهامش الربح وتكلفة الخامات % والهالك % والمصروفات والمشتريات والمستهدف %.
- **جسر الأرباح**: يبدأ من المبيعات ثم يطرح تكلفة المبيعات فيظهر مجمل الربح، ثم يطرح المصروفات والهالك وعجز الجرد فيظهر صافي الربح.
- **توزيع المصروفات**: نصيب كل تصنيف من المصروفات.
- **المبيعات حسب القناة**: صافي المبيعات لكل قناة بيع.
- **حالة مزامنة واكتمال البيانات**: آخر مزامنة لكل فرع وحالته: متصل أو متأخر أو غير متصل.

## مثال على جسر الأرباح

فرع باع 200,000 ج.م في الشهر:

| البند | القيمة |
|---|---|
| المبيعات | 200,000 ج.م |
| تكلفة المبيعات (-) | 64,000 ج.م |
| مجمل الربح | 136,000 ج.م |
| المصروفات (-) | 90,000 ج.م |
| الهالك (-) | 4,000 ج.م |
| عجز الجرد (-) | 2,000 ج.م |
| صافي الربح | 40,000 ج.م |

هامش الربح هنا 40,000 ÷ 200,000 = 20%.

::: warning تنبيه
إذا ظهر فرع بحالة **متأخر** أو **غير متصل**، فقد تكون أرقامه ناقصة. افتح [حالة البيانات والاتصال](./data-health) قبل اتخاذ قرار.
:::
